# Data Model

## Alias
| Field | Type | Rules |
|-------|------|-------|
| name | string | `^[A-Za-z0-9_.][A-Za-z0-9_.@+:-]*$`, 1-64 chars, unique across all groups |
| command | string | non-empty; stored verbatim (any characters incl. newline) |
| group | string | `^[a-z0-9][a-z0-9_-]*$`; inferred from command unless pinned |
| pinned | bool | true when the group was set explicitly; stops re-inference on update |

## Store file (`aliases.toml`)
```toml
version = 1

[git]
gp = "git pull"
gs = "git status"

[helm]
hgp = "helm get pods"

[_pinned]            # names whose group was set explicitly
names = ["hgp"]
```
- Group table names are group names; `version` and `_pinned` are reserved and cannot be groups.
- A name appears in exactly one group table; duplicates on load are an error naming the file and key.
- Hand edits are honoured; unknown top-level keys are preserved on save where the library allows, otherwise rejected with a clear error.

## Generated file (`aliases.zsh`)
Derived, never edited by hand; header says so.
```zsh
# generated by ali; do not edit
for _n in $_ali_names; do unalias -- "$_n" 2>/dev/null; done
_ali_names=(gp gs hgp)
alias -- gp='git pull'
...
```

## State transitions
add → (exists? error / --force replace) → saved → render.
update → command replaced; group re-inferred iff not pinned.
regroup → group moved, pinned = true.
rm → deleted; if group empty its table is dropped.
