# Implementation Plan: Oh My Zsh compatibility

**Branch**: `002-omz-compat` | **Date**: 2026-11-08 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/002-omz-compat/spec.md`

## Summary

The `ali()` wrapper in `.zshrc` runs inside the user's shell, so it can see aliases and functions that the binary cannot. It hands that information to the binary (an environment variable for `add`, stdin for `doctor`). The generated `aliases.zsh` remembers any pre-existing alias it overrides in a session-only zsh associative array and restores it when ali's alias goes away. `ali init` learns to replace an outdated block in place.

## Technical Context

**Language/Version**: Go 1.24+, zsh 5.x shell code generated by `internal/render`

**Primary Dependencies**: unchanged (cobra, go-toml/v2)

**Storage**: unchanged store; no new persisted state

**Testing**: unit tests per package; e2e in sandbox `HOME` with an Oh My Zsh-like `.zshrc` (plugin aliases defined before the block); no real Oh My Zsh needed in CI

**Target Platform**: macOS + zsh (unchanged)

**Project Type**: CLI

**Performance Goals**: shell startup cost < 1 ms extra (SC-005); `add` unchanged

**Constraints**: the wrapper must stay hijack-safe (ADR 0021): every builtin backslash-escaped

**Scale/Scope**: ~200 Oh My Zsh aliases plus up to 1,000 ali aliases
